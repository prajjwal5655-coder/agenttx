Weekly Report Flow
==================

1. Scheduler triggers agent workflow every Friday at 14:00
2. Agent invokes: query_orders (reads sales-db)
   - Query: SELECT order_id, customer_name, total_amount FROM orders WHERE week = current
3. Agent invokes: generate_report (formats summary)
   - Output: Human-readable text summary of sales data
4. Agent invokes: send_to_manager (emails to regional managers)
   - Channel: email
   - Recipients: managers@company.example (8 addresses)
